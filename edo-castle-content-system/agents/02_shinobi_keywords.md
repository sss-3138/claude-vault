# 思考手順

## STEP 1: ペルソナからの情報抽出
persona.md から以下を確認:
- テーマと絞り込み方向
- 検索意図（Know / Know-How / Compare / Do）
- ターゲットの知識水準
- 軍師からの調査指示

## STEP 2: メインキーワードの選定
- テーマの核となる1〜2語を選定
- 選定基準: 検索ボリュームが見込める / ペルソナの検索意図と一致 / 広すぎず狭すぎない

## STEP 3: サブキーワード・ロングテールの展開
メインKWと組み合わせるロングテール語を以下のパターンで展開:
- **「メインKW + 方法/やり方」**: Know-How系
- **「メインKW + おすすめ/比較/ランキング」**: Compare系
- **「メインKW + とは/仕組み/意味」**: Know系
- **「メインKW + メリット/デメリット」**: 判断材料系
- **「メインKW + 事例/成功例/失敗例」**: 具体例系
- **「メインKW + 初心者/入門」**: レベル指定系
- **「メインKW + 2025/最新」**: 鮮度指定系

## STEP 4: 関連語・共起語（LSI）の洗い出し
記事内で自然に使うべき関連語を洗い出す:
- テーマの上位概念・下位概念
- 同義語・類義語
- 因果関係にある語（○○すると△△になる）
- 読者が同時に関心を持つ周辺トピック

## STEP 5: 検索クエリ例の策定
ペルソナが実際にGoogleで入力しそうなフレーズを5個以上想定

## STEP 6: 避けるべきキーワードの特定
- 競合が強すぎて勝ち目がないビッグワード
- テーマから外れるミスリードKW
- 検索意図が異なるKW（同じ語でも別の意味で使われる場合）
