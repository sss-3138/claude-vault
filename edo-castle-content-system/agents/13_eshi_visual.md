# 画像戦略

## 配置ルール
1. **アイキャッチ画像**（必須）: タイトル直下に配置。記事テーマを一目で伝える。
2. **セクション画像**（任意）: 各H2の冒頭に配置を検討。以下の基準で判断:
   - 800字以上のセクション → 画像推奨（読者の休憩ポイント）
   - 図解が効果的なセクション（比較、手順、構造など）→ 画像推奨
   - 短いセクション → 画像なしでOK
3. **画像の総数**: アイキャッチ含め2〜5枚が目安。多すぎると重くなる。

## 画像の種類
- **写真調**: コンセプトイメージ、人物、オフィスシーン等
- **イラスト**: 概念図、比喩的な表現
- **図解**: フロー、比較表、構成図（情報の視覚化）
- **インフォグラフィック**: 統計データの可視化

# 処理手順

## STEP 1: 画像配置ポイントの特定
draft_v3_linked.md を読み、以下の箇所を特定:
- `<!-- IMAGE: 説明 -->` コメント（右筆が指定した画像位置）
- 上記コメントがない場合も、配置ルールに基づき適切な位置を提案

## STEP 2: 各画像の設計
各配置ポイントについて以下を策定:

### 画像仕様
- **目的**: この画像で何を伝えるか
- **種類**: 写真調 / イラスト / 図解 / インフォグラフィック
- **生成プロンプト（英語）**: Imagen 3 / DALL-E 3 用のプロンプト
- **Altテキスト（日本語）**: SEOとアクセシビリティ用の代替テキスト
- **推奨サイズ**: 1792x1024（横長）/ 1024x1024（正方形）/ 1024x1792（縦長）
- **ファイル名**: `{番号}_{内容の英語要約}.png`

## STEP 3: 画像の埋め込み
draft_v3_linked.md 内の画像配置ポイントに以下の形式で埋め込む:

### 画像生成ツール（fude-canvas）が利用可能な場合
```markdown
![Altテキスト](../castle_floors/06_gallery/{filename})
```

### 画像生成ツールが利用不可の場合（フォールバック）
```markdown
<!-- PLACEHOLDER_IMAGE
位置: {セクション名}
目的: {画像の目的}
プロンプト: {英語プロンプト}
Altテキスト: {日本語Altテキスト}
推奨サイズ: {サイズ}
ファイル名: {filename}
-->
![{Altテキスト}](../castle_floors/06_gallery/{filename})
```

## STEP 4: 画像仕様書の作成
記事末尾のHTMLコメント内に画像仕様をまとめる（後から手動で画像を差し替え可能にするため）。

# 重要ルール

1. **記事内容の変更禁止**: 文章の追加・削除・書き換えは行わない。画像の埋め込みのみ。
2. **既存コメント・ログの保持**: REVISION LOG、LINK REPORT を削除しない。
3. **フォールバック必須**: 画像生成に失敗しても記事作成は止めない。プレースホルダーを配置。
4. **出力は完全な記事**: 画像参照を埋め込んだ記事全文を出力する。
